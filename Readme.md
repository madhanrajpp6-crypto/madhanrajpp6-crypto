## 🚀 Featured Projects

### 🩺 MEDI-M JOE — Voice-First AI Healthcare Assistant

A healthcare-focused AI assistant designed to provide basic health information, work with user-provided health parameters, provide wellness guidance, and manage reminders.

**Highlights**
- 🎙️ Voice-first interaction
- 🤖 AI-powered healthcare assistance
- ❤️ Heart-rate related features
- 🔊 Rime TTS voice
- 🎤 Speech-to-text integration
- 🌐 REST API backend
- 🛡️ Designed as a college-level healthcare prototype

**Tech:** \`AI\` \`Voice AI\` \`Node.js\` \`REST API\` \`Rime TTS\` \`Deepgram\`

---

### 🌾 AgroLink Direct — Connecting Farmers & Industries Directly

A digital agriculture marketplace concept designed to connect farmers and industries directly while reducing dependency on intermediaries.

**Highlights**
- 🌱 Farmer & industry marketplace
- 📍 Location & map integration
- 📦 Product listings
- 💬 Negotiation & messaging
- 🚚 Logistics concept
- 🤖 AI-assisted features

**Tech:** \`JavaScript\` \`Node.js\` \`MongoDB\` \`Maps\` \`AI\`

---

### ❤️ Smart Health Monitoring System — Embedded Biomedical Monitoring Prototype

An IoT-enabled biomedical prototype combining physiological and motion sensors for health-parameter monitoring and activity/fall-related detection.

**Hardware:** \`Arduino UNO\` \`ESP32\` \`MAX30102\` \`MPU6050\` \`SIM800L\`

**Focus**
- ❤️ Heart Rate
- 🫁 SpO₂
- 📈 Health Monitoring
- 🏃 Motion Detection
- 🚨 Emergency Alerts
- ☁️ IoT Connectivity
